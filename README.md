# DevCentr Homebrew tap (+ Scoop bucket)

## Homebrew

```bash
brew tap dev-centr/tap
brew install ibex
```

(`dev-centr/homebrew-tap` is the GitHub repo; Homebrew short name is `dev-centr/tap`.)

## Scoop

```powershell
scoop bucket add dev-centr https://github.com/dev-centr/homebrew-tap
scoop install ibex
```

Formulas and Scoop JSON are updated when Ibex releases; SHA256 placeholders are filled after each tagged GitHub Release.
